# Contract E03 — Kernel Version & Userspace Syscall/Libc ABI Compatibility Matrix

## Scope & Mission
Defines the per-board-class kernel ABI capability matrix (`franken_platform::KernelCapabilityMatrix`), runtime capability probing, and safe fallback selection across the legacy Linux `2.6.14` (PowerPC S5/ZB100) and `2.6.35` (MIPS32r2 S1/S3/S9/S12/Sub) kernels as well as the Debian `4.9` (BE-PPC) and `4.19` (BE-MIPS) QEMU harness kernels.

## Verified Capability Matrix

| Capability | Stock PPC (`2.6.14`) | Stock MIPS (`2.6.35`) | QEMU BE-PPC (`4.9.0-0.bpo.6-powerpc`) | QEMU BE-MIPS (`4.19.0-21-4kc-malta`) | Fallback Strategy |
|---|---|---|---|---|---|
| `clock_gettime(CLOCK_MONOTONIC)` | `VerifiedAvailable` | `VerifiedAvailable` | `VerifiedAvailable` (`PASS`) | `VerifiedAvailable` (`PASS`) | Mandatory (hard boot gate) |
