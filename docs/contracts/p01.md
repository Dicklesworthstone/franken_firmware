# Contract P01 — FrankenFirmware Cargo Workspace & Crate Topology

## Scope & Mission
Defines the layered Rust 2024 Cargo workspace for `franken_firmware`, enforcing `#![forbid(unsafe_code)]` across all protocol, session, clock, stream, control, and DSP crates, static memory budgeting with a hard `>= 4 MiB` free-headroom floor on 32 MiB PowerPC boards (`S5` Play:5 Gen1), and deterministic cross-compilation to `powerpc-unknown-linux-musl` and `mips-unknown-linux-musl`.

## Crate DAG & Layer Boundaries

1. `franken-test-support` (`Q00`): Deterministic SplitMix64 network impairment schedule, sample continuity oracle, epoch fencing oracle, command idempotency oracle, readiness truthfulness oracle, secret-redacting non-blocking sink, and JSON receipt schema.
2. `franken-board-profile` (`E01`): Board profiles (`S1`, `S3`, `S5`, `S9`, `S12`, `Sub`, `ZB100`), SHA-256 profile digests, provenance verification, and permutation-invariant fleet reconciliation.
3. `franken-platform` (`E03`, `P02`, `P05`): Kernel capability matrix (`2.6.14` PPC / `2.6.35` MIPS / `4.x` QEMU), `portable-atomic` 64-bit atomic wrapper (`AtomicU64`, `AtomicI64`, `MonotonicEpochCounter`), and static memory budget verifier (`MemoryBudget`).
4. `franken-hal` (`E04`, `P04`): Typestate audio DMA HAL (`Closed ->OpenMuted -> Prepared -> Running -> FaultedMuted`) enforcing silence priming before unmute and DMA lease quarantine on drop.
5. `franken-dsp` (`D01`..`D04`): Deterministic `f32` audio blocks, big-endian `i16` wire conversion, 4-point Hermite fractional ASRC (`<= 500 ppm`), DC blocker, Linkwitz-Riley crossover, and soft-knee transducer protection limiter.
6. `franken-clock` (`N03`, `V01`, `V02`): IEEE 1588v2-lite PTP Follower PI servo, outlier rejection, holdover/resync state machine, per-board calibrated output delay compensation, and automatic YouTube/AirPlay lip-sync delay reporting.
7. `franken-stream` (`N01`, `N04`..`N06`): Authenticated `FFWP` audio frames (`HMAC-SHA256`), 64-packet sliding replay window, `consume_by` deadline enforcement, 4-packet XOR parity FEC, and bounded jitter buffer with cosine PLC fade.
8. `franken-session` (`G01`, `G02`, `N02`): Unified S1+S2 group coordinator (`UnifiedGroupSession`), epoch fencing, command sequence idempotency, logarithmic volume laws, and stop-tail silence zeroing.
9. `franken-control` (`G03`, `S01`, `A01`, `T01`, `X01`): `fsonos`-compatible UPnP/SOAP/GENA shim, Spotify Connect (`librespot`) session state machine, AirPlay 2 receiver adapter, Alexa intent bridge with confirmation gate, and Tailscale remote-access control boundary.
10. `franken-speaker` (`P01`, `Q01`, `UX01`): Top-level speaker daemon (`franken-speaker --self-test` / `--virtual-house`) and multi-room virtual house harness.
