# E02 contract: incumbent resource and dropout baseline analyzer (ffw-za4)

**Status.** Offline analyzer and its synthetic qualification. **No incumbent resource or dropout capture
exists in either repository, and nothing here measures a device.** Live measurement is a separate,
externally authorised receipt that this analyzer would consume. A passing run proves the analyzer, not
any speaker.

Code: `crates/franken-baseline` (`forbid(unsafe_code)`, no dependencies in the library). CLI:
`ffw-baseline series|memory|compare`. Cases: `tests/e02/` (`cases.json` maps every invariant to a case).
The synthetic inputs are in `tests/e02/synthetic/`, deliberately not `captures/`: the repository's
`.gitignore` excludes `captures/` so that real device captures can never be committed here. A real
incumbent capture, when one exists, stays outside git and is fed to the analyzer by path.
Entry point: `scripts/e2e/e02`. Central build: `RCH_REQUIRE_REMOTE=1 rch exec -- cargo test -p franken-baseline`.
All arithmetic is integer; reports are one line of JSON.

## Inputs

**Series capture** (`ffw.baseline.capture.v1`), one record per line, `#` comments:

```
meta evidence=synthetic profile=P cadence_ms=1000 declared_ms=10000 [playout_ms= hole_factor_pct=150
     wall_step_ms=1000 spike_factor=8 device_rate_hz= device_width=64 device_stall_frames=
     min_coverage_ppm= max_dropout_intervals=]
counter name=N role=dev_underruns|late_packets|cpu_misses|source_bytes|other width=32|64 [max_rate_per_s=0]
gauge   name=N role=playing|value [max=]
sample  mono_ns=T [wall_ns=W] [dev_frames=F] name=value ...
```

`evidence` is `synthetic | host-simulation | guest-execution | real-service | physical`. The thresholds
(`min_coverage_ppm`, `max_dropout_intervals`) are declared in the capture, before the run. A series
missing from a sample is a missing value, not zero. Unknown keys, undeclared series, duplicate names or
roles, declarations after samples and non-integer values are errors with a line number.

**Memory snapshots** (`ffw.baseline.memory.v1 page_size=4096 [reserve_kib=]`): `snapshot label= at_mono_ns=`
then `--- meminfo | status pid= | smaps_rollup pid= | statm pid=` sections holding the raw `/proc` text.
Kernel `kB` means KiB; `statm` counts pages and converts only through the declared page size.

## What each result means

- **Coverage** `observed_ns / declared_ns` in ppm. An interval longer than `cadence * hole_factor_pct`
  is a **hole**: reported with its length and estimated swallowed samples, **never interpolated**.
  A capture ending early is **truncated**; the missing time is reported, not extrapolated.
- **Counters.** A rise is a delta. A fall is a **wraparound** only for a 32-bit counter whose wrapped
  delta fits under `max_rate_per_s * dt`; otherwise a **reset**, which has no rate and censors its span.
  Events in a hole or reset are `unlocated_events_min`, kept out of every rate.
- **Clock domains** are separate types. Gaps and rates use only the monotonic clock. A wall-clock step
  is reported as a step and creates no gap. The device sample clock is related to monotonic time by
  `drift_ppm`; a 32-bit wrap there is not a stall.
- **Dropouts.** A dropout interval is an uncensored interval in which the underrun counter rose (or the
  device clock fell short by the declared stall). **With no such signal the dropout count is `unknown`,
  never zero**, and a "zero dropouts" threshold is then not met.
- **Cause** per dropout, judged only from each candidate's own signal over a window (the interval, the
  interval before it, and any earlier interval ending within `playout_ms` of its start), and only if
  that signal is complete over the window:
  `source_outage` (source bytes stalled while playing), `network_lateness` (late-packet counter rose),
  `cpu_deadline_miss` (deadline-miss counter rose). Exactly one firing is `determined` and lists the
  candidates it could not rule out; two or more is `ambiguous`; none firing with all three observed and
  quiet is `output_underrun` (only for a counted underrun); anything else is `undetermined` and **names
  the missing signals**. No cause is ever guessed.
- **Memory.** RSS comes from `smaps_rollup`, else `status`, else `statm`; disagreeing sources are
  findings, not averaged. Shared pages are counted once via PSS and the naive-RSS overstatement is
  reported (`double_counted_kib`). Kernel memory (slab, kernel stacks, page tables) is a separate line.
  `unattributed_kib` is a signed residual, not a measurement of any consumer. Headroom is judged only
  against a `reserve_kib` declared in the input.
- **Absolute verdict** (`qualified | not_qualified | not_assessed`) only against the capture's own
  declared thresholds. It needs no baseline.
- **Comparative claims.** `compare` returns a comparison only against a `Baseline`, which can be built
  only from a **`physical`** capture with at least 900 000 ppm coverage and a known dropout rate, and
  only if the current run is also physical, of the same profile, with no censored dropouts. Otherwise it
  is refused with a reason (exit 3). A synthetic capture can never be a baseline or an improvement.

## Not proven

- Anything about a device, kernel, driver or network: inputs are synthetic.
- That a cause is *the* cause: `determined` means that candidate's signal fired and every other
  observable signal was quiet. Unobserved candidates are listed, not excluded.
- That a quiet capture is dropout-free beyond its observed time and its sampling cadence.
- That `unattributed_kib` is driver or DMA memory; it is whatever the simple model leaves over.
- Anything about 24-hour behaviour, group synchronisation or CPU deadlines on a board: those are the
  later campaigns and need their own authorised receipts.

## Verification

`tests/e02/oracle.py` (stdlib) re-derives each series and memory report independently; the Rust
integration test `crates/franken-baseline/tests/e02_cases.rs` runs the real binary over the same
captures against the same hand-written expected files, plus planted-difference tests of its own matcher.
Cancellation and restart do not apply (a pure batch function with no partial output); see
`cases.json`.
